# 2026-04-23_集成豆包API真实调用

## 修改内容

### config.py
- 新增 `DOUBAO_MODEL = "doubao-seedream-4-5-251128"` 模型名称
- 新增 `OUTPUT_DIR` 输出目录配置，指向项目下 `output/` 文件夹

### main.py
- 新增 `GenerateThread(QThread)` 异步生成线程类：
  - 调用豆包 `doubao-seedream-4-5-251128` 模型生图 API
  - 支持多图输入（image 字段传入 base64 data URI 列表）
  - 生成结果自动下载保存到 `output/` 目录
  - 通过 `result_ready` / `error_occurred` 信号通知主线程
- 重写 `callDoubaoAPI` 方法：
  - 本地图片转 base64 data URI
  - 构建 prompt（根据是否含姿势/场景参考图动态调整）
  - 启动 `GenerateThread` 异步执行，避免 UI 卡死
- 新增 `onGenerateResult` / `onGenerateError` 回调方法
- 新增 `imageToBase64` 静态方法，支持 jpg/png/bmp/webp 格式
- `generateImage` / `batchGenerate` 改为调用异步 API

## API 调用格式
```
POST https://ark.cn-beijing.volces.com/api/v3/images/generations
Headers: Authorization: Bearer {API_KEY}
Body: {
    "model": "doubao-seedream-4-5-251128",
    "prompt": "...",
    "image": ["data:image/png;base64,...", ...],
    "sequential_image_generation": "disabled",
    "response_format": "url",
    "size": "2K",
    "stream": false,
    "watermark": true
}
```
