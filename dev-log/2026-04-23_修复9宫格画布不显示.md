# 2026-04-23_修复9宫格画布不显示问题

## 修改内容
- `ImageCanvas` 从 `setGeometry` 绝对定位改回 `QVBoxLayout` 布局方式
- 原因：`setGeometry` 在 GridLayout 下会被布局管理器覆盖，导致 label 不可见
- 修复后：layout margins 2px，label 最小尺寸 76×76，widget 固定 80×80
- 同时修复了布局警告 `QLayout::addChildLayout: layout already has a parent`
- 将 `grid_layout.addLayout(...)` 改为 `grid_layout.addWidget(widget, ...)` 避免布局嵌套冲突
