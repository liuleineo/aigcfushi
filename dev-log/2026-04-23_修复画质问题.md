# 2026-04-23_修复画质问题-提升到豆包app同等水平

## 问题分析
豆包API生成的图片不如豆包app高清，原因有三：

### 1. 分辨率太低
- 之前：`"size": "2K"` → 最大 2048×2048
- 修复：`"size": "4K"` → 最大 4096×4096，与豆包app一致

### 2. 图片传输有压缩损失
- 之前：`"response_format": "url"` → 返回URL，下载时经过JPEG二次压缩
- 修复：`"response_format": "b64_json"` → 直接返回base64原始数据，零损失

### 3. 保存方式损失
- 之前：从URL下载的二进制数据直接保存为PNG（实际是JPEG数据存为PNG）
- 修复：从base64直接解码保存，保留API返回的原始画质

## 其他调整
- 请求超时从120s增加到180s（4K生成时间更长）
