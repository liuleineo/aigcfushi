## Windows exe 打包
- PyInstaller 不支持跨平台打包，macOS 上无法生成 Windows exe
- 已创建 `build_win.bat` 脚本，需在 Windows 环境下运行：
  1. 安装 Python 3.14
  2. 运行 `pip install pyinstaller PyQt5 requests`
  3. 双击 `build_win.bat` 即可生成 `dist\女装AI创作画布.exe`

## 打包命令
```
pyinstaller --noconfirm --windowed --onefile \
    --name "女装AI创作画布" \
    --add-data "config.py:." \
    main.py
```
- `--windowed`：不显示控制台窗口
- `--onefile`：打包为单个文件
- `--add-data`：包含 config.py 配置文件
