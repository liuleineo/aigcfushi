# 批量生成改为3并发执行

## 改动内容
- `self.gen_thread` 改为 `self.active_threads` 列表，支持多个并发线程
- 新增 `self.gen_active` 记录当前活跃线程数，`self.max_concurrent = 3` 最大并发数
- `_processQueue` 改为循环启动，直到活跃线程数达到3或队列为空
- 新增 `_updateBatchTitle` 显示批量生成进度（完成/执行中/等待）
- `onGenerateResult` / `onGenerateError` 完成后递减 `gen_active`，清理已完成线程，再尝试启动新任务
- `processImage` 右键处理也改用 `active_threads` 列表
